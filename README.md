# Ejercicios con Fold en Wollok

Este repositorio contiene una serie de ejercicios realizados en **Wollok** para practicar el uso del método `fold` sobre colecciones.

El objetivo principal es entender cómo recorrer listas y construir distintos resultados usando acumuladores.

## Temas trabajados

En este proyecto se practican operaciones sobre listas utilizando `fold`, tales como:

- Sumar los elementos de una lista.
- Multiplicar los elementos de una lista.
- Encontrar el máximo de una lista.
- Invertir una lista.
- Implementar un comportamiento similar a `map` usando `fold`.
- Implementar un comportamiento similar a `filter` usando `fold`.
- Aplanar una lista de listas.
- Implementar comportamientos similares a `any` y `all` usando `fold`.
